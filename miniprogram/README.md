# 微信小程序客户端

原生微信小程序，复用现有 FastAPI 抓取和摘要数据。不需要构建前端依赖。

## 开发预览

1. 部署本仓库后端，保留现有数据库；设置 ADMIN_PASSWORD 保护管理界面。
2. 修改 config.js 的 apiBase 为自己后端的 HTTPS 域名。不要填任何管理员密码、模型密钥或微信 AppSecret。
3. 在微信开发者工具中导入本目录，用自己的小程序 AppID 替换 project.config.json 的 touristappid。测试号仅供开发。
4. 在微信公众平台配置 request 合法域名，并在开发者工具和真实手机分别验证。生产不要关闭域名校验。

正式发布还需要用户自己的微信主体/AppID、服务器域名及合规配置、内容来源授权和微信审核。资讯聚合的可用服务类目及资质以账号后台当前要求为准。本项目没有代注册或提交审核。

## 已实现

- 今日简报、今天/3天/7天筛选、来源筛选、关键词搜索。
- 分页、下拉刷新、触底加载、空态、错误重试、旧请求防覆盖。
- 中文摘要详情、技术标签、分享、复制原文链接。
- 本机收藏（最多100条），不采集微信身份，不上传收藏。
- API 只读，不触发抓取、模型调用或消息推送。不暴露管理配置和密钥。

外链不使用 web-view，避免假设第三方来源都能加入业务域名。PROTECT_SITE=1 的私有站点会被 API 拒绝，小程序暂不实现账号认证；不要为了接入小程序关闭原本需要的访问保护。面向公众发布前需确认公开资讯范围。

微信订阅消息、微信登录和跨设备收藏尚未实现，原有企业微信机器人推送也不等同于小程序订阅消息。

## 验证

`node --test miniprogram/tests/*.test.js`（从仓库根目录）。还必须在微信开发者工具真机验证：分享直达、返回、连续切换筛选、弱网重试、收藏取消、首次无数据。云端测试不能代替微信运行时验收。

## 云端真实接口联调

已提供 `scripts/smoke-miniprogram.cjs`：先启动后端并抓取数据，再从根目录运行 `SMOKE_API_BASE=http://127.0.0.1:8765 node scripts/smoke-miniprogram.cjs`。脚本使用真实小程序页面逻辑与请求模块，将 wx.request 桥接到 Node fetch，验证列表、分页、详情、搜索、空态和错误处理；不验证 WXML 渲染、微信登录或真机能力。后端需与测试脚本运行在同一网络会话。

云端开发工作区不是持续公网托管服务。正式使用应单独部署 HTTPS 后端并配置微信合法域名。使用 SOCKS 代理的环境已由 httpx[socks] 依赖支持。
